# LYNX SIGHT

Experimental optical input device of the LYNXware ecosystem: cameras that track the eyes, head
and, later, gestures, for computer input. This repository holds the v0.1 prototype.

| Path | Contents |
|---|---|
| `software/diagnostic/` | Linux dual-camera diagnostic tool ([README](software/diagnostic/README.md)) |
| `hardware/` | 3D-printable camera mount |
| `docs/architecture/` | shared interfaces ([cameras, rig frame, experiment config](docs/architecture/shared-interface.md)) |
| `docs/testing/` | test plans and results ([camera hardware tests](docs/testing/hardware-test-plan.md)) |
| `docs/hardware/` | camera and mount hardware documentation |
